Exemplo de Interfaces em Java
Descrição

Este projeto apresenta um pequeno exemplo prático do uso de interfaces na linguagem Java, demonstrando como uma interface pode ser utilizada para desacoplar componentes de um sistema.

O exemplo consiste em um sistema simples de notificações, no qual diferentes formas de envio de mensagens podem ser utilizadas sem que o componente consumidor precise conhecer os detalhes de cada implementação.

Exemplo de saída
===== SISTEMA DE NOTIFICAÇÕES =====

Enviando e-mail...
Mensagem: Sua conta foi criada com sucesso!

Enviando SMS...
Mensagem: Seu código de confirmação é 1234.
Tecnologias utilizadas
Java
Programação Orientada a Objetos
Interfaces
Desacoplamento de componentes
